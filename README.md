## 🚀 Quick Start (Development)

Requires **Node.js 20.19+** (or **22.12+**):

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev

# 3. Open browser at http://localhost:5173
```

---

## 📦 Production Build

```bash
# Build production assets into /dist
npm run build

# Preview production build locally
npm run preview
```

---

## 📄 Standalone Single-File Version

The included `ecosystem-share.html` is 100% self-contained. You can double-click it to open in any web browser without needing Node.js or any terminal commands.
